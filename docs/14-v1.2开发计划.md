# V1.2 开发计划 — 理财攒钱 + 体验打磨

> **版本**：v1.2.0
> **日期**：2026-10-04
> **定位**：从"能用"到"好用"——补全用户自用最高频的储蓄目标功能，同时打磨手机端体验
> **上游**：v1.1.3 已验收通过（9/9），核心双人记账+云同步链路稳定
> **开发模式**：vibecoding（HTML+Tailwind+原生JS，纯静态，GitHub Pages 部署）

---

## 一、版本目标

1. **补全理财攒钱核心能力**：F1 储蓄目标看板（用户自用最高频，"30岁存100万"场景）
2. **解决实测暴露的体验问题**：F16 视角锁、手机端输入法遮挡、错误提示说人话
3. **保持小步快跑**：2-3周完成，每个批次结束产品可运行

## 三、P0 功能详细设计

### 3.1 F1 储蓄目标看板

#### 3.1.1 入口与位置

- 看板页（📊）顶部新增"储蓄目标"卡片，位于月度汇总下方
- 设置页 → 储蓄目标 → 可编辑目标参数

#### 3.1.2 目标设置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 目标金额 | 数字 | 1,000,000 | 总储蓄目标，支持手动修改 |
| 目标日期 | 日期 | 用户30岁生日 | 截止日期，支持手动修改 |
| 起始金额 | 数字 | 当前家庭结余 | 已存金额，默认取当前结余，可手动覆盖 |
| 起始日期 | 日期 | 今天 | 开始日期，用于计算进度 |

> 目标为**家庭共同目标**，两端同步。小金库不计入共同储蓄（隐私隔离）。

#### 3.1.3 进度展示（看板卡片）

```
┌─────────────────────────────────┐
│  🎯 储蓄目标                      │
│  ┌──────┐                       │
│  │ 进度环│  已存 ¥156,000       │
│  │ 15.6%│  目标 ¥1,000,000      │
│  └──────┘  剩余 3年2个月         │
│            每月需存 ¥22,400      │
│  [编辑目标]                       │
└─────────────────────────────────┘
```

- **进度环**：SVG 环形进度条，百分比居中
- **已存/目标**：金额对比
- **剩余时间**：目标日期 - 今天，按"X年X个月"显示
- **每月需存**：(目标金额 - 已存金额) / 剩余月数，自动测算

#### 3.1.4 攒钱测算（智能提示）

基于当前**月均结余**（近3个月平均），测算能否达成目标：

| 情况 | 提示文案 | 样式 |
|------|---------|------|
| 当前月均结余 ≥ 每月需存 | "按当前节奏，预计可提前X个月达成目标 🎉" | 绿色 |
| 当前月均结余 < 每月需存（差距≤20%） | "按当前节奏，还差一点，每月多存¥XXX即可达成" | 橙色 |
| 当前月均结余 < 每月需存（差距>20%） | "按当前节奏可能无法按期达成，建议每月存¥XXX（当前月均结余¥XXX）" | 红色 |

> 月均结余 = 近3个月（收入-共同支出）的平均值，不含小金库。

#### 3.1.5 里程碑激励

- 预设里程碑：10万、30万、50万、80万、100万（可自定义）
- 达成里程碑时：看板卡片显示🎉动画 + "恭喜达成第一个10万！"
- 里程碑记录：设置页可查看历史达成时间

#### 3.1.6 数据存储

- LocalStorage key：`finance_savings_goal`
- 云同步：纳入家庭设置同步（复用 v1.1.3 家庭设置云同步机制）
- 字段：targetAmount、targetDate、startAmount、startDate、milestones[]

#### 3.1.7 验收标准

- [ ] 看板页显示储蓄目标卡片，进度环百分比正确
- [ ] "每月需存"金额 = (目标-已存)/剩余月数，计算正确
- [ ] 编辑目标后，进度和测算实时更新
- [ ] 攒钱测算提示根据月均结余显示正确颜色和文案
- [ ] 达成里程碑时显示庆祝动画
- [ ] 两端同步后目标参数一致
- [ ] 小金库金额不计入共同储蓄

### 3.2 F16 视角锁 + 切换提示

#### 3.2.1 视角锁开关

- **入口**：设置页 → 隐私与安全 → "锁定当前身份视角"
- **开关默认**：关闭（可切换）
- **开启后**：
  - 顶部身份切换按钮隐藏或置灰
  - 点击置灰按钮时 toast："视角已锁定，如需切换请先到设置页解锁"
  - 结算页、明细页的身份切换入口同步禁用
- **解锁**：设置页关闭开关 → 输入口令（复用现有"身份切换锁"口令，如未设置则要求先设置）

#### 3.2.2 切换时隐私提示

- 每次切换视角时（无论是否开启视角锁），弹窗提示：

```
┌─────────────────────────────┐
│  切换到「小棠」视角           │
│                              │
│  切换后：                     │
│  ✅ 可看到对方的公开账目       │
│  🔒 对方私密账仅显示占位行     │
│  💰 对方小金库完全不可见       │
│                              │
│  [确认切换]    [取消]         │
└─────────────────────────────┘
```

- 弹窗可勾选"不再提示"（存入 LocalStorage）
- 设置页可重新开启提示

#### 3.2.3 验收标准

- [ ] 设置页有"锁定当前身份视角"开关
- [ ] 开启后身份切换按钮不可用，点击有提示
- [ ] 解锁需输入口令
- [ ] 切换视角时弹窗显示隐私边界说明
- [ ] 勾选"不再提示"后切换不弹窗
- [ ] 两端各自独立锁定状态（A锁了不影响B）

### 3.3 手机端体验优化

#### 3.3.1 输入法遮挡

- 所有输入框 focus 时，调用 `element.scrollIntoView({block: 'center'})`
- 记一笔页：金额输入框 focus 时，自动滚动到表单可见区域
- 注册/登录弹窗：输入框 focus 时，弹窗整体上移

#### 3.3.2 触摸区域

- 所有可点击元素（按钮、tab、列表项）最小触摸区域 **44×44px**
- 底部导航 tab 高度 ≥50px
- 记一笔 FAB 按钮直径 ≥56px
- 检查当前所有按钮是否有过小的情况，统一调整

#### 3.3.3 加载状态与防重复点击

- **同步按钮**：点击后显示"同步中..."+转圈，禁用按钮，完成后恢复
- **注册/登录按钮**：同上
- **保存按钮**（记一笔）：点击后禁用，保存成功后自动关闭表单
- **删除/确认结算**：点击后禁用，防止连点

#### 3.3.4 下拉刷新（可选，P2）

- 明细页支持下拉刷新，触发"立即同步"
- 实现：touchstart/touchmove/touchend 监听，下拉距离>80px 触发

#### 3.3.5 验收标准

- [ ] 记一笔页金额输入时，输入框不被输入法遮挡
- [ ] 注册弹窗输入时，弹窗可见
- [ ] 所有按钮触摸区域≥44px
- [ ] 同步/注册/保存按钮点击后有 loading 状态，不能重复点击
- [ ] 快速连点保存只产生一条记录

### 3.4 错误提示说人话

#### 3.4.1 错误文案映射表

| 技术错误 | 用户友好文案 | 操作 |
|---------|------------|------|
| Failed to fetch / NetworkError | "网络不太好，检查网络后重试" | 显示+重试按钮 |
| 邀请码无效/过期 | "邀请码不对或已过期，让对方重新生成一个" | 显示 |
| 邮箱已注册 | "这个邮箱已经注册过了，直接登录吧" | 显示+切换登录按钮 |
| 密码错误 | "密码不对，再想想" | 显示 |
| 邮箱格式错误 | "邮箱格式好像不对" | 显示 |
| Supabase 项目暂停/503 | "服务暂时不可用，等几分钟再试" | 显示+重试按钮 |
| 同步冲突 | "有更新，已自动合并" | toast 提示 |

#### 3.4.2 统一错误提示组件

- 建立 `showError(title, message, retryCallback)` 全局函数
- 样式：底部 toast 或居中弹窗，根据错误严重程度选择
- 网络类错误统一带"重试"按钮
- 所有 `catch` 块调用统一组件，不再直接 `alert(error.message)`

#### 3.4.3 验收标准

- [ ] 断网时注册/同步显示"网络不太好"，不是"Failed to fetch"
- [ ] 输入错误邀请码显示用户能看懂的提示
- [ ] 网络错误有"重试"按钮
- [ ] 所有错误提示不暴露技术细节（如 API key、堆栈信息）

## 四、P1 功能（视进度纳入）

### 4.1 F4 支出预算与超支提醒

- 设置页 → 预算管理 → 按分类设月预算（餐饮/交通/购物等）
- 记一笔时：如果该分类本月已超预算，输入金额下方显示红色提示"本月餐饮已超支¥XXX"
- 看板页：分类预算进度条（已花/预算），超支标红
- 数据存储：LocalStorage + 云同步

### 4.2 F8 月度收支趋势

- 看板页新增"近6个月收支趋势"折线图
- X轴：月份，Y轴：金额，两条线（收入/支出）
- 点击某个月可跳转查看该月明细
- 实现：原生 SVG 或 Chart.js（CDN）

### 4.3 F11 同步冲突提示

- 同步时检测到本地和云端都修改了同一笔记录
- 当前行为：LWW（最后写入优先）静默覆盖
- 新行为：toast 提示"有更新，已自动合并"，不阻断流程
- 高级（P2）：冲突列表，用户可选择保留哪版

## 七、风险与依赖

| 风险 | 影响 | 应对 |
