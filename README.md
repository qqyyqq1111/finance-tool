# 双人家庭 AI 理财助手（finance-couple）

> 面向情侣 / 小两口的**本地离线隐私型**双人记账 Web 工具。
> 纯静态：HTML5 + Tailwind CSS（CDN）+ 原生 JS，无构建、无后端、无框架；数据全部保存在本设备浏览器 LocalStorage，**永不联网上传**。

- 当前版本：**v1.0.0**（记账 + 三层隐私 + 分摊结算 + 仪表盘 + 本地加密）
- AI 能力（自然语言记账等）规划在 v1.1

---

## 一、怎么运行

**方式 A：直接打开**
双击 `index.html` 即可（推荐 Chrome / Edge 最新版）。

**方式 B：本地服务（推荐，加密能力更稳）**
在项目目录执行：

```bash
python -m http.server 8642
```

浏览器访问 `http://localhost:8642`。

**部署**：纯静态，直接把整个目录扔到 GitHub Pages / Netlify / Vercel 即可。

## 二、使用说明（操作手册）

### 1. 首次建账（三步向导）
1. 填家庭昵称（如"我们的家"）
2. 填两位成员昵称和表情（如"阿晨 🧑 / 小棠 👩"）
3. 设置默认分摊比例（如 50:50，之后可在结算页改）

### 2. 记一笔（底部 ＋ 按钮）
- **类型**：支出 / 收入
- **金额**：元为单位（底层以"分"整数存储，无浮点误差）
- **日期**：默认今天，可补记/补改
- **分类**：餐饮、房租水电、交通、购物、娱乐、医疗、人情、其他……可在设置里增删/隐藏
- **归属人**：这笔是谁的账
- **隐私层级**（核心功能，三层）：
  | 层级 | 本人 | 对方 | 进统计/分摊 |
  |---|---|---|---|
  | 🌐 公开 | 可见 | 可见 | 参与分摊 |
  | 🔒 私密 | 可见 | 只见一条灰色占位"对方有 1 笔私密记录" | 不进分摊、不进对方统计 |
  | 💰 小金库 | 可见 | **完全无痕**（连占位行都没有） | 不进分摊、不进对方统计 |
- **参与分摊**：仅"公开支出"可开关；私密/小金库自动关闭
- 保存后：点击明细页任意账目行 → 弹出详情 → 可**编辑 / 删除**

### 3. 明细页
- 顶部"💰 我的小金库"卡片：仅本人可见，点击展开明细
- 月份切换（‹ ›）：按月浏览，显示当月收入/支出
- 列表：自己的账目正常显示；对方的私密账显示灰色占位行；对方小金库账不出现

### 4. 分摊结算（底部"结算"Tab）
- 自动统计当月**公开且参与分摊**的支出：谁垫付多少、各自应承担多少
- 支持自定义比例：默认比例（如 5:5）+ 按分类覆盖（如"房租 3:7、购物 2:8"）
- **比例在记一笔落账时固化**：之后改比例不影响历史月份
- 操作：**确认结算**（锁定当月账目，禁增改删）→ **标记结清**（线下转账后点）→ 如算错可**作废**解锁
- 尾差自动处理：如 33.33 元 5:5 → 16.67 / 16.66，总额永远守恒

### 5. 仪表盘（底部"看板"Tab）
- 本月结余 / 收入 / 支出（大字）
- 支出分类占比 Top5（纯 CSS 图表）
- 双人"垫付 vs 应承担"对比（仅公开共同支出口径）
- 我的小金库余额
- 记账坚持天数（正向激励）
- 所有数字随"查看人身份"自动切换口径

### 6. 身份切换（右上角头像胶囊）
- 点击切换"我是谁在看"→ 全应用数据按该身份的可见范围重算
- 模拟两人共用一台设备各自查看（v1.0 单设备方案）

### 7. 设置页
- **双人身份**：点卡片切换身份；点 ✏️ 可改昵称/表情（成员固定两位，不可增删）
- **数据备份与导出**：
  - 导出/导入 JSON：全量备份恢复（**建议每月一次**，清浏览器缓存会丢数据）
  - 导出 CSV：仅导出**当前查看人可见**的账目，Excel 可直接打开
- **数据加密**（可选开关，默认关闭）：
  - AES-GCM-256 加密，口令经 PBKDF2（15 万次）派生密钥，密钥不存本机
  - 加密对象：交易与结算数据；昵称/分类等元数据不加密
  - 开启后刷新/锁定需输 6 位口令解锁；**忘记口令数据无法恢复**
- **分类管理**：预置分类可隐藏不可删；自定义最多 12 个；有账目的分类不可删
- **版本模式**（商业化演示开关）：
  - 免费版：仅单人公开记账，双人/隐私/结算/CSV 等入口隐藏
  - 家庭会员版：全功能
- **数据体检 / 演示数据**：开发自测用

## 三、隐私与安全

- 数据 100% 存于本设备浏览器 LocalStorage（key 前缀 `fc_`），无任何网络上报
- 三层隐私在取数层（`js/privacy.js`）统一过滤，页面无法绕过
- 小金库数据可开启 WebCrypto 加密（密文落盘，密钥仅内存）
- 清除浏览器站点数据 = 账本清空，请养成 JSON 备份习惯

## 四、目录结构与测试

```
index.html          应用单页（含向导/五个Tab页/弹层）
js/
  db.js             数据层（LocalStorage、校验、备份、加密桥接）
  crypto.js         WebCrypto 加密（AES-GCM + PBKDF2）
  privacy.js        三层隐私过滤纯函数
  split.js          分摊结算引擎 + 结算页
  dashboard.js      仪表盘纯函数 + 看板页
  ledger.js         记一笔表单 + 明细列表 + 小金库视图
  settings.js       设置页（身份/分类/备份/加密/版本）
  app.js            启动、导航、版本门控
test/               Node 单测（无框架，node test/xxx.test.js 直接跑）
docs/               产品文档（MRD/PRD/路线图等 8 份）
```

跑测试：

```bash
node test/privacy.test.js    # 隐私矩阵 18 项
node test/split.test.js      # 分摊结算 30 项
node test/dashboard.test.js  # 看板/分类/版本 26 项
node test/crypto.test.js     # 加密 34 项
```

共 108 项断言全过。
