# 双人家庭AI理财助手 · 人工评测清单

> 用途：邀请朋友/同事帮忙实测产品，收集真实用户体验反馈
> 预计耗时：15～20 分钟 ｜ 全程本地运行，测完可一键清空数据，不留痕迹

---

## 一、评测前准备（给测试者）

**这是什么？**
一款「双人家庭记账 + 月底分摊结算」的本地小工具。两人共用一台电脑/一个浏览器，各自记账、月末自动算出谁该给谁多少钱，还有私密账和小金库隐私保护。

**怎么打开？**（任选其一）
- 方式 A（推荐，最简单）：把项目里的 `index.html` 文件直接拖进 Chrome / Edge 浏览器打开
- 方式 B：命令行进入项目目录，运行 `python -m http.server 8642`，浏览器访问 `http://localhost:8642`

**测试建议**
- 全程用**假数据**（下方有统一测试数据脚本），不要记真实财务信息
- 建议用**无痕/隐身窗口**打开，测完不保留缓存
- 测完想清空：设置页 → 最底部「清空数据，退出当前家庭…」→ 输入"退出"两字确认

**统一测试数据**（请按这个脚本录入，便于对比结果）
| 项目 | 值 |
|---|---|
| 家庭名 | 幸福小窝 |
| 成员A | 阿晨 |
| 成员B | 小棠 |
| 分摊比例 | 默认 50% : 50%（不动） |
| ① 公开支出 | 128 元 · 餐饮 · 阿晨付 · 参与分摊 · 备注"和对象吃火锅" |
| ② 公开支出 | 3500 元 · 房租水电 · 小棠付 · 参与分摊 · 备注"9月房租" |
| ③ 私密支出 | 800 元 · 购物 · 阿晨付 · 选「单笔私密」· 备注"护肤品" |
| ④ 小金库收入 | 3000 元 · 其他收入 · 阿晨 · 选「小金库」· 备注"私房钱" |
| ⑤ 公开收入 | 15000 元 · 工资 · 小棠 · 备注"9月工资" |

> 按以上数据，月底结算预期为：**阿晨 应付 小棠 ¥1,686.00**（共同支出 3628 ÷ 2 = 1814/人；阿晨只垫付了 128，需补 1686）
