## 1. 项目基本信息

### 1.1 项目名称与定位

| 项目 | 内容 |
|------|------|
| **项目名称** | 双人家庭AI理财助手 |
| **一句话定位** | 一款面向22-35岁年轻情侣/夫妻的「本地离线隐私型双人AI家庭理财Web工具」 |
| **产品形态** | HTML5 + Tailwind CSS v3 + vanilla JS 纯静态Web工具（v1.0-v2.0），后续考虑PWA |
| **数据存储** | 浏览器 LocalStorage（全量本地，日常功能完全离线；仅AI解析场景临时联网） |
| **AI能力** | 基于 Kimi 大模型（OCR识别+Excel解析+自然语言记账） |
| **付费模式** | 单人免费版引流 → 双人家庭会员版付费（年费200-300元） |
| **项目目的** | ①个人自用 ②求职作品集（突出AI Agent落地+B端标准化设计+SaaS商业化） |

### 1.2 核心差异化（与全部竞品的对比）

市面上**没有任何一款产品**同时覆盖以下能力：

1. **三层隐私架构**：公开（共同可见）→ 单笔私密（知道存在但看不到内容）→ **小金库完全隐藏（对方不知道该账户存在）**
2. **本地离线存储**：全量数据 LocalStorage + 加密，日常功能无需联网/注册
3. **AI自动化记账**：语音/OCR/Excel批量导入，基于Kimi大模型
4. **双人财务规则引擎**：自定义分摊+自动结算+**工资归集+零用钱自动发放**（行业唯一）
5. **正向激励体系**：储蓄里程碑+成就徽章+浮亏安抚

### 3.2 三层隐私架构（核心设计决策）

这是用户文档审阅后**重大设计升级**。场景：一方想攒小金库，完全不想让另一方知道。

| 层级 | 名称 | 伴侣可见范围 | 适用场景 | 备注 |
|------|------|------------|---------|------|
| **Layer 1** | 公开 | 全部明细可见 | 房租、餐饮、旅行 | 默认状态 |
| **Layer 2** | 单笔私密 | 知道"存在私密支出"，但看不到内容 | 个人购物、礼物 | 标记单笔 |
| **Layer 3** | 小金库完全隐藏 | **不知道该账户存在** | 私房钱、个人储蓄 | 独立账户 |

> **决策背景**：Bankrate/Fidelity调研显示88%年轻情侣保留私人小金库。小金库是健康财务关系的必要组成部分，产品设计应正面推广。
